# 🧪 Testing Workflow Pattern - Mfcnextgen Project

## **Established Pattern Agreement**

I commit to following this exact testing pattern for all future testing requests to ensure 100% correct and reliable output.

## **📋 Standard Testing Workflow**

### **Phase 1: Problem Analysis & Planning**
1. **Understand the Problem**: Clearly identify what needs to be tested
2. **Use Playwright MCP**: For browser-based testing and analysis
3. **Create Todo List**: Track progress with specific, actionable items
4. **Plan Approach**: Determine the best testing methodology

### **Phase 2: Test Implementation**
1. **Use Playwright MCP Tools**:
   - `mcp__playwright__browser_navigate()` for page navigation
   - `mcp__playwright__browser_evaluate()` for DOM analysis
   - `mcp__playwright__browser_snapshot()` for element location
2. **Systematic Analysis**: Check all relevant pages and components
3. **Issue Identification**: Pinpoint exact locations with CSS selectors
4. **Evidence Collection**: Provide before/after comparisons

### **Phase 3: Documentation & Reporting**
1. **Comprehensive Reporting**: Provide exact file paths, line numbers, and code locations
2. **Visual Evidence**: Include screenshots and element snapshots when relevant
3. **Clear Recommendations**: Specific actionable items for fixes
4. **Verification**: Confirm changes are working correctly

### **Phase 4: Implementation Support (if requested)**
1. **Precise File Modifications**: Use exact string replacements
2. **Git Integration**: Proper commit practices and version control
3. **Quality Assurance**: Verify no regressions introduced
4. **Deployment**: Push changes to remote repository

## **🎯 Key Principles**
